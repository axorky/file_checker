cmd/server - main.go - основной файл с бэкендом, с подключением на локал хост. Запуск локалхоста, после чего по нему на сайте будет поле для загрузки файла, который будет проверяться

front - Indext.html - собственно код фронтенда

pkg/modules - папка с модулями для работы в main.go. Рабочие модули, некоторые из них не подключены к функциям компании Лайтигард, из-за чего работают всего 2 из 4-ех, но включать и выключать модули можно через json файл в коревой папке - modules.json

pkg/database - база с данными о файле, которые загружают, в случае повтора ввода того же файла - выводиться результат
